# 🪙 FinanzArg

> Aplicación web moderna y minimalista de control de gastos personales desarrollada como desafío final para APX.

🔗 **Link de la aplicación en producción:** [https://finanzarg-gamma.vercel.app/](https://finanzarg-gamma.vercel.app/)

---

## 🚀 Características Principales

- **Gestión de Transacciones:** Permite registrar ingresos y egresos diarios de manera rápida e intuitiva.
- **Edición y Eliminación:** Posibilidad de modificar o eliminar transacciones ya cargadas en cualquier momento.
- **Gráfico de Gastos por Categoría:** Visualización gráfica en formato de "torta" (doughnut chart) interactiva que desglosa los egresos según la categoría.
- **Modo Oscuro / Claro:** Adaptación visual completa para cuidar la vista o ajustarse a las preferencias del sistema operativo.
- **Persistencia de Datos:** Almacenamiento local mediante `localStorage` para que la información no se pierda al recargar la página.
- **Formato Localizado:** Visualización de fechas en formato `dd/mm/yy` y valores monetarios adaptados (`$ ARS`).

---

## 🛠️ Tecnologías Utilizadas

Este proyecto fue construido utilizando tecnologías modernas del ecosistema frontend:

- **React 18** (con Hooks)
- **TypeScript** (tipado estricto)
- **Vite** (empaquetador y entorno de desarrollo rápido)
- **Tailwind CSS** (estilos y diseño responsivo)
- **Lucide React** (iconografía moderna)
